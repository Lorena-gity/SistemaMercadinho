# Diagramas UML

`diagrama-classes.puml` — diagrama de classes do sistema (camadas MVC + Service + DAO
e os padrões Singleton, Factory, Facade e Strategy).

## Como visualizar

- VS Code: extensão "PlantUML" (Alt+D para pré-visualizar).
- Online: cole o conteúdo em https://www.plantuml.com/plantuml.
- CLI: `plantuml docs/uml/diagrama-classes.puml` (gera o PNG ao lado).
